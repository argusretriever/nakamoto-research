Profile knowledge

Investor profiles guide personalization

Profiles help readers see their likely needs, risks, and next steps without pretending to give personalized advice.

Map stage and goal

A beginner, accumulator, retiree, trader, and researcher need different education paths.

Example: ETF basics before thesis writing for a new investor.

  • Mistake: serving every user the same content.
Respect risk capacity

Profile should include time horizon, income stability, cash needs, and emotional tolerance.

Example: a high-earner with near-term cash need may still need conservative assets.

  • Mistake: using age alone.
Recommend next artifact

Each profile should produce a checklist, roadmap, or dashboard path.

Example: portfolio builder gets an IPS template.

  • Mistake: ending with a label only.
