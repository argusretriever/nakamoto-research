# NAKAMOTO Design System

Updated: 2026-06-26

## Direction

NAKAMOTO should feel like a premium research publication: monochrome, calm, precise, editorial, and trustworthy. The visual system must support long reading sessions, source verification, daily return habits, and clear navigation across the four priority sectors.

## Palette

Use pure monochrome first:

1. Black: primary text, primary buttons, brand mark, high-emphasis rules.
2. White: page canvas, cards, inverse button text.
3. Gray: muted text, borders, table lines, metadata, secondary controls.
4. Silver: subtle motion fields, logo atmosphere, premium highlights.

Avoid colored gradients, orange Bitcoin glow, green finance palettes, pink/red accents, and decorative color blobs unless the owner explicitly asks for a separate campaign asset.

## Typography

Use system UI typography for speed and clarity. Headings should be large, tight, and editorial. Body copy should stay readable, restrained, and high contrast. Avoid negative letter spacing beyond existing display treatments.

## Layout

Prefer clean editorial bands, clear section hierarchy, and card grids that help readers choose a next action. Avoid stacked decorative panels, visual clutter, and background patterns that compete with text.

## Motion

Motion should be subtle and useful:

1. Logo atmosphere may move slowly in monochrome.
2. Cards may lift slightly on hover.
3. Focus states must be immediate and visible.
4. Respect reduced-motion preferences.

## Components

Buttons, cards, forms, tags, and navigation should use shared monochrome tokens. Cards should feel tactile but not loud. Buttons should clearly separate primary action from secondary exploration.

## Accessibility

Every theme must preserve strong contrast, visible focus states, readable body copy, usable mobile tap targets, and reduced-motion compatibility.

## Brand Rule

If a design choice makes the site feel noisier, more colorful, more generic, or less trustworthy, remove it. NAKAMOTO should feel quiet, expensive, useful, and built for the next decade.
