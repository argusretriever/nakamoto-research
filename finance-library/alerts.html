Alert knowledge

Alerts should improve discipline, not noise

A good alert reminds investors to review a rule, source, or assumption rather than chase every price movement.

Alert the process

Set reminders for earnings, rebalancing, Fed meetings, review dates, and thesis triggers.

Example: alert when a 10-Q is released, not every intraday move.

  • Mistake: turning alerts into anxiety.
Use thresholds carefully

Thresholds should connect to a written action.

Example: allocation drift threshold triggers review.

  • Mistake: setting alerts without knowing what to do.
Control frequency

Too many alerts make users numb.

Example: weekly summary for watchlist changes.

  • Mistake: real-time alerts for long-term decisions.
