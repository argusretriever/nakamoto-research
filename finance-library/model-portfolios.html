Model portfolio knowledge

How model portfolios should be used

A model portfolio is an educational starting point, not a personalized prescription. It should teach allocation logic, tradeoffs, and review rules.

Understand the job

Each model should explain growth, stability, income, tax awareness, and complexity tradeoffs.

Example: aggressive growth models accept larger drawdowns for longer horizons.

  • Mistake: copying a model without matching goals.
Review assumptions

Time horizon, risk capacity, savings rate, tax status, and cash needs change the right allocation.

Example: two investors can both be 40 and need different portfolios.

  • Mistake: using age as the only input.
Define rebalance rules

A model is incomplete without review cadence and drift bands.

Example: rebalance when target bands break, not whenever markets move.

  • Mistake: confusing model allocation with daily trading.
