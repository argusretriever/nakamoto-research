Churn rescue

When learning stalls, do not quit. Shrink the next step.

Trading education becomes heavy when the learner has too many topics, no practice rhythm, weak risk rules, or no visible progress. This page turns friction into a smaller recovery action.

Rescue library

Five repair paths for common student drop-offs.

Each rescue route is designed to reduce cognitive load and restore action. The goal is not more information; it is a better next step.

Path 01

Overwhelmed

Restart at onboarding, choose one goal, and ignore advanced modules for seven days.

Restart onboarding
Path 02

Not practicing

Use a 15-minute block: one concept, one chart, one note, one next action.

Build practice plan
Path 03

Breaking rules

Return to risk sizing, drawdown limits, and a written pre-trade checklist.

Open risk tool
Path 04

Lost path

Retake the assessment and let the platform choose the next learning route.

Take assessment
Path 05

No progress

Review a sample batch, identify one weak area, and work one mistake pattern.

Open review lab
Path 06

Still stuck

Ask one precise office-hours question with context, chart, rule, and confusion point.

Ask office hours

Continuation loop

Rescue, then return to the dashboard.

The rescue page is a temporary repair tool. Once the learner has one clear action again, progress should move back into onboarding, lessons, challenges, and review.
