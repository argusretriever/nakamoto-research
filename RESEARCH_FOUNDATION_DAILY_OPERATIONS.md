# NAKAMOTO Research Foundation Daily Operations

Use this checklist for the new research foundation sections:

1. Data & Analytics
2. Statistics
3. Risk Management
4. Economic History
5. Geopolitics
6. Research Methods
7. Tools & Calculators
8. Guides & Tutorials
9. Corporate Finance
10. Capital Markets

These sections support the main Nakamoto education system. They should make the website more serious, source-led, useful, and authoritative without creating fake freshness.

## Daily Operation

Each day, choose 2-3 sections from this list and improve one useful thing in each selected section.

Daily improvements can include:

1. Improve one paragraph.
2. Add one plain-English example.
3. Add one source or source route.
4. Add one internal link to a priority hub.
5. Add one internal link from a priority hub back to the section.
6. Improve one checklist.
7. Improve one tool explanation.
8. Improve one heading.
9. Improve one meta description if needed.
10. Check that wording stays educational and non-advisory.

## Section Tasks

### Data & Analytics

1. Update one useful data point or dashboard route.
2. Check one source link.
3. Add one explanation of what the data means.
4. Link to related Bitcoin, markets, investing, or research page.

### Statistics

1. Add or improve one concept: probability, volatility, correlation, base rates, sample size, drawdown, or backtests.
2. Add one plain-English example.
3. Link to risk, trading, investing, or data pages.
4. Avoid false certainty from numbers.

### Risk Management

1. Improve one risk checklist.
2. Add one practical warning.
3. Link to Trading Academy, Bitcoin safety, Investing, or Personal Finance.
4. Check that no wording sounds like financial advice.

### Economic History

1. Add one historical example.
2. Explain what is similar and what is different today.
3. Link to macro, Bitcoin, gold, central banks, or capital markets.
4. Avoid "history will repeat" claims.

### Geopolitics

1. Add one global event explanation when relevant.
2. Connect it to markets, currencies, energy, commodities, or policy.
3. Avoid sensational predictions.
4. Use source-led context.

### Research Methods

1. Improve one research checklist.
2. Add one source-quality rule.
3. Link to source tracker, official data hub, statistics, or data analytics.
4. Strengthen fact-vs-interpretation clarity.

### Tools & Calculators

1. Test one calculator or tool.
2. Improve one tool explanation.
3. Add one "use this when" note.
4. Link tools back to guides and priority hubs.

### Guides & Tutorials

1. Improve one tutorial.
2. Add one next-step checklist.
3. Improve one beginner path.
4. Link guide to tool, source, and related article.

### Corporate Finance

1. Add or improve one concept: cash flow, margins, debt, equity, treasury, valuation, or capital allocation.
2. Link to business, capital markets, investing, or Bitcoin treasury context.
3. Keep it education-only.
4. Avoid company-specific investment recommendations.

### Capital Markets

1. Add or improve one concept: stocks, bonds, ETFs, credit, liquidity, primary markets, or secondary markets.
2. Link to investing, ETFs, bonds/yields, global markets, or macro.
3. Keep it source-led and non-advisory.
4. Avoid buy/sell language.

## Weekly Operation

Once per week:

1. Review all 10 research foundation sections.
2. Improve weak pages.
3. Add missing internal links.
4. Check mobile layout.
5. Check metadata.
6. Add one stronger guide, example, source route, or checklist.
7. Confirm all 10 sections are reachable from `sections.html`.
8. Confirm all 10 sections are findable through site search.

## Monthly Operation

Once per month:

1. Upgrade the research hierarchy.
2. Add deeper guides.
3. Add better tools or checklists.
4. Merge duplicate topics.
5. Review Google/Microsoft data for clicks, impressions, and rankings when available.
6. Decide which section deserves a full pillar-page upgrade.
7. Review topical authority gaps across data, risk, history, geopolitics, research, finance, and markets.

## Rotation

1. Monday: Data & Analytics + Capital Markets + Risk Management.
2. Tuesday: Statistics + Trading/Risk + Tools & Calculators.
3. Wednesday: Economic History + Macroeconomics + Bitcoin.
4. Thursday: Geopolitics + Commodities + Forex/Currencies.
5. Friday: Research Methods + Guides & Tutorials + Sources.
6. Saturday: Corporate Finance + Business + Investing.
7. Sunday: Review all 10 lightly and improve internal links.

## Rules

1. Do not fake daily updates.
2. Do not add filler.
3. Do not make financial advice claims.
4. Do not make unsupported predictions.
5. Do not use sensational geopolitical language.
6. Use official sources where possible.
7. Keep every section connected to the four priority hubs.
8. Improve usefulness before volume.
