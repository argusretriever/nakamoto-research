Usage rules

How every diagram earns its place.

The design rule is simple: if a graphic does not clarify the decision, it does not ship.

One Concept

Each visual teaches one primary idea. Supporting labels explain context but do not compete with the main pattern.

One Decision

Every chart graphic shows what the learner should observe, compare, accept, reject, or review.

One Next Step

Each component connects to a lesson, drill, glossary term, checklist, worksheet, or case study.
