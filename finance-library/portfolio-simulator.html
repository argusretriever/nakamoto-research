Simulation literacy

Portfolio simulation knowledge

A simulator helps test ranges, not predict the future. It should make assumptions visible and encourage scenario thinking.

Run scenarios

Use conservative, base, and optimistic assumptions.

Example: test lower returns and higher inflation before trusting the result.

  • Mistake: planning around one expected return.
Separate nominal and real

Nominal values ignore inflation; real values estimate purchasing power.

Example: 7% nominal with 3% inflation is roughly 4% real before taxes.

  • Mistake: comparing future dollars without inflation.
Use outputs as prompts

Simulation results should lead to contribution, allocation, or goal review.

Example: shortfall means review savings rate before chasing risk.

  • Mistake: treating a model as certainty.
