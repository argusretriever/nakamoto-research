Tool methodology

How to use investing tools responsibly

A calculator is only as useful as the assumptions behind it. Tools should clarify inputs, limits, and what the result can actually support.

Inputs drive outputs

Contribution, return, inflation, fees, taxes, and time horizon assumptions can change results dramatically.

Example: 7% nominal and 4% real returns tell different stories.

  • Mistake: treating projections as promises.
Use ranges, not single numbers

Run conservative, base, and optimistic cases before making a decision.

Example: compare 4%, 6%, and 8% return scenarios.

  • Mistake: planning around only the best case.
Connect tools to next steps

A tool should lead to a checklist, guide, or review action.

Example: fee calculator result should lead to ETF comparison.

  • Mistake: calculating without changing the process.
