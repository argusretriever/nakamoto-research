Keep consumer prices, input costs and factory-gate prices on separate rows

Published 18 November 2026

Build an inflation comparison that identifies the index, reference month, measurement stage and release date.

Start with a published reference month

In the September 2026 releases, annual CPI inflation was 3.5%, producer input inflation was 8.3% and producer output inflation was 4.6%. CPI tracks consumer prices, input PPI covers manufacturers’ material and fuel costs, and output PPI covers factory-gate prices.

Write a comparison you can verify

  1. Make one row per index and label September as the reference month.
  2. Copy the annual rate and keep the monthly rate in a separate column.
  3. Save the release date and note any revisions to the earlier month.
  4. Identify which spending or production stage each series covers.

Earlier source check

At the 04:22 London check on 18 November, the ONS marked the October consumer-price release unpublished. Its scheduled time was 07:00. When the new bulletin appears, repeat the rows for October and check September revisions before comparing changes.
