# NAKAMOTO Academy Site

Private static website for NAKAMOTO Academy, a visual trading education platform.

## Contents

- Trading education homepage and curriculum pages
- Student learning tools, lessons, labs, resources, study paths, and risk setup pages
- Shared CSS and JavaScript in `assets/`
- `sitemap.xml` and `robots.txt`

## Run Locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Safety

NAKAMOTO Academy is education only. It does not provide investment advice, trade signals, managed accounts, or guaranteed trading outcomes.
