Privacy

Privacy must be part of the product.

NAKAMOTO Money Library's financial context is sensitive. The production product should be explicit about data collection, storage, deletion, and third-party tools.

Current static build

Local-only calculators

The current static calculators run in the browser and do not connect to a database or API.

Production requirement

Consent and deletion

If accounts, dashboards, or saved plans are added, users need clear consent, export, deletion, and security controls.

Analytics and consent

Measure respectfully

NAKAMOTO Money Library uses Microsoft Clarity, Google Analytics, Microsoft Promotion, and Google publisher Promotion to understand page views, traffic sources, device types, and broad engagement patterns. Calculators run in the browser, and NAKAMOTO Money Library should not intentionally send private calculator inputs such as income, debt balances, savings amounts, or net worth to analytics.

Security

Protect sensitive context

Use HTTPS, secure cookies, rate limits, input validation, encryption at rest, and least-privilege access for any backend launch.
