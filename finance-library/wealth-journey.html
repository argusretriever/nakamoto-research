Journey knowledge

The investor journey should create progress

A journey platform should move readers from awareness to practice: assess, learn, apply, review, and improve.

Assess before prescribing

Investor stage, goals, risk capacity, and behavior determine the right path.

Example: a beginner and retiree need different lessons and tools.

  • Mistake: giving every user the same next step.
Progress requires proof

Learning should create artifacts: policy statement, watchlist, thesis, checklist, or review log.

Example: completing a portfolio lesson produces a written allocation rule.

  • Mistake: reading without output.
Return loops build habit

Daily brief, weekly recap, monthly review, and annual reset create durable engagement.

Example: recurring reviews make the platform essential.

  • Mistake: relying only on new articles.
