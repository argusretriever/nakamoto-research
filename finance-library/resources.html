Resource knowledge

Resources should become reusable investor assets

A resource library is valuable when it helps readers repeat a good decision process, not just collect links.

Templates create consistency

A template turns a one-time idea into a repeatable workflow.

Example: an investment policy statement prevents improvising during volatility.

  • Mistake: saving resources but never using them.
Checklists reduce omissions

A checklist catches fees, taxes, risks, sources, and next actions.

Example: ETF checklist includes spread, index, overlap, and tax profile.

  • Mistake: using memory for complex decisions.
Worksheets teach judgment

A worksheet should force assumptions into the open.

Example: thesis worksheet asks what would make the idea wrong.

  • Mistake: only documenting bullish evidence.
