History knowledge

Market history teaches humility

History provides base rates and analogies, but every cycle is different. Use it to widen perspective, not predict perfectly.

Study regimes

Inflationary, recessionary, expansionary, and liquidity-driven markets behave differently.

Example: bonds and stocks do not always diversify the same way.

  • Mistake: using one decade as universal rule.
Respect drawdowns

Long-term returns include painful declines.

Example: a portfolio plan should assume bear markets will happen.

  • Mistake: planning only with averages.
Use base rates

History helps estimate ranges of possible outcomes.

Example: compare current valuations with long-term forward return ranges.

  • Mistake: treating an analogy as destiny.
