Learning path

How to learn investing in the right order

Investing education works best when foundations come before tactics and tools come before opinions.

Learn accounts before assets

Account type affects tax treatment, access, and contribution rules.

Example: taxable, traditional, Roth, and employer accounts each serve different jobs.

  • Mistake: picking funds before understanding account constraints.
Learn risk before return

Expected return is meaningless if the investor cannot tolerate the path.

Example: a high-return strategy can fail if drawdowns force selling.

  • Mistake: chasing return without risk capacity.
Learn review habits

The best investors build repeatable review systems.

Example: monthly learning, quarterly portfolio review, annual policy update.

  • Mistake: mistaking screen time for education.
