Dashboard literacy

Research dashboard knowledge

Dashboards should show signals, sources, and interpretation rules so users understand what to do next.

Avoid overloaded charts

A dashboard should prioritize a few important signals.

Example: valuation, rates, breadth, earnings, and risk appetite.

  • Mistake: adding every metric.
Label refresh dates

Users need to know whether data is current.

Example: economic releases update on schedules.

  • Mistake: showing stale data without a timestamp.
Turn signals into questions

Dashboards should ask what to review.

Example: narrow breadth asks whether portfolio concentration is rising.

  • Mistake: using colors as commands.
