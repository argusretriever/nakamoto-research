Framework knowledge

Investment frameworks are decision tools

A framework is useful when it makes a decision clearer, repeatable, and easier to audit.

Define the question

Every framework starts with a decision question.

Example: Should this ETF be core, satellite, or rejected?

  • Mistake: using a framework without a decision.
State assumptions

Assumptions should be visible and revisitable.

Example: growth, margins, rates, inflation, and behavior assumptions.

  • Mistake: hiding uncertainty.
Create review triggers

A framework should say when to revisit the decision.

Example: rebalance, thesis break, valuation change, or goal change.

  • Mistake: never updating the framework.
