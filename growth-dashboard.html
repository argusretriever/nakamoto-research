Review System

Use real data. Do not guess.

Google

Search Console.

Review impressions, clicks, CTR, position, indexed pages, sitemap status, and pages that deserve updates.

Google

Analytics 4.

Check pages with engagement, return visits, low engagement, outbound clicks, form events, and reader paths.

Review sitemap submission, indexing, crawl issues, search performance, and Bing-specific recommendations.

Microsoft

Advertising and UET.

Weekly Questions

The questions that improve traffic.

Content

Which page deserves a better answer?

Update pages with impressions but weak CTR, thin depth, weak intros, missing internal links, or poor next steps.

Discovery

Which page is orphaned?

Add homepage, section, related article, course, glossary, or calculator links so important content is easier to find.

Retention

Which page needs a second click?

Add course routes, worksheets, comparison links, source packs, and newsletter routes where they help the reader.

Analytics note

This dashboard organizes review work. It does not claim live analytics results. Use Google and Microsoft dashboards as the source of truth.
